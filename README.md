🎮 YLUMA PRO — Site Conceito

⚠️ PROJETO CONCEITUAL — NÃO É UM PRODUTO REAL

O YLUMA PRO foi desenvolvido como um site de teste/conceito, criado para visualizar como seria uma página de vendas caso eu decidisse criar e vender um controle gamer no futuro.

A ideia foi simular uma marca de periféricos gamer, incluindo identidade visual, apresentação do produto, especificações, benefícios e uma possível página de compra.

💡 Sobre o projeto

Este projeto não representa um produto real disponível para venda.

O controle YLUMA PRO é fictício e as informações apresentadas no site, como:

1000Hz de Polling Rate
Hall Effect Sticks
40 horas de bateria
Microprocessador de 32-bits
RGB
Design ergonômico

foram utilizadas apenas como parte do conceito e da demonstração do site.

🎯 Objetivo

O objetivo principal foi testar e praticar a criação de um site comercial moderno, simulando uma situação real de lançamento de um produto.

O projeto explora elementos como:

🛒 Página de venda
🎮 Apresentação de produto
💻 Design tecnológico
🎨 Identidade visual
📱 Interface moderna
⚡ Animações e interações
📊 Apresentação de especificações
🎨 Identidade Visual

O design do YLUMA PRO foi inspirado em produtos Gaming e Cyberpunk, utilizando principalmente:

🟢 Verde neon
⚫ Preto
⚪ Branco
🔵 Tons escuros

A intenção foi criar uma aparência que transmitisse tecnologia, velocidade e desempenho.
